## 坐标

- ENU：米，东 E、北 N，原点是 OSM 上夕焼けだんだん台阶顶（35.727641, 139.767341）。
- 换算到 qs_h1：`x = 1.8 - N`，`y = E + 32.5`，`z = PLATEAU 高程 - 7.95`。
- 这个对齐让现有模型的台阶底（y=1.4）落在真实台阶底 E=-31.1，让街道中线 x=0 落在真实街道 N=1.8。
- 注意：模型台阶水平长 14.4 米，OSM 约 31 米，所以台阶顶以东不能这样直接对位。

GLB 实测范围（qs_h1）：A x 17.16—56.8，y -91.51—-21.6；B x -47.27—-11.1，y -83.5—-17.5。两者都在 5070 给的安全线外（南 x>14.5，北 x<-11）。

## 总装要处理

- 现有街道是平的（z≈0），新街块按真实地形约有 ±0.45 米的东西向坡度，接缝要做坡或抬路。
- 现有沿街楼是连续的、没有横街，而真实路网在 E≈-58（qs_h1 y≈-25.5）有一条南北路。玩家要走进新街块，需要在沿街楼上开口。
- 新街块地面盖在 `ground` 上，范围内的远景卡片和天际线盒子要移除。
- 灯光没有烘焙。新街块只有 UV0，5070 总装时要生成光照贴图 UV。
- 地面边缘是裁切线，道路不会自己延伸到地块外。
