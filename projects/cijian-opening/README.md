# 此间 · 单页开头

原四人角色选择 → 第一视角图书馆行走 → 靠近发光古书按 F → 原有完整翻书转场。唯一入口是 `开头.html`，场景在同一文档内切换。图书馆已删除顶部旅人/视角/任务文字与底部操作说明。

## 获取与运行

此目录包含运行所需模型、背景、字体、视频与 Three.js 模块，无外网 CDN 依赖。二进制资源采用 Git LFS，协作者需先获取 LFS 实体：

```powershell
git lfs install
git lfs pull
cd projects/cijian-opening
python launch.py
```

Windows 也可双击同目录 `启动开头.bat`。需要 Python 3 和支持 WebGL 的浏览器。启动器只监听本机地址；不要直接以 `file://` 运行 ES 模块。

WASD / 方向键行走，点击画面后鼠标转向，Esc 释放，近书按 F；R 重置位置。翻书结束后可以返回图书馆或重新选角。详细说明见 [使用说明](使用说明.md)、[开发接入说明](开发接入说明.md)。

## 验证与范围

独立 Edge 1280×720 已检查四人物、同页切换、CN 进入、WASD/方向键、相对鼠标转向、近书 F 完整播放、防重复触发，以及重选 Noah 再进入；无运行异常或资源缺失。指针锁定与实际设备帧率仍待实机体验，完整记录见 [验证结果](验证结果.md)。

图书馆与四人物、古书模型和视频沿用项目已有资产。结尾地图为既有视频的装饰性示意；可玩东京/悉尼、NPC 剧情、手部抓握和终章回忆卡尚未接入。本目录不是已上线或全流程完成的游戏。

`文件清单.json` 保存本机交付包的 29 个运行/说明文件及 SHA-256；此 README 和 Git 属性为上传时新增的仓库说明，不在原清单中。原模型、字体及第三方依赖继续遵循各自来源和许可条件。
