# 此间 · 开头

双击 `启动开头.bat` 开始。唯一页面为 `开头.html`，包含原四人选择动效、第一视角图书馆和 F 翻书；页面内连续切换，不再在 HTML1/HTML2 之间跳转。

选角后按 Enter 进入图书馆。WASD / 方向键行走；点击画面后鼠标转向，Esc 释放鼠标；靠近发光书本按 F。触屏可用方向按钮和 F 按钮。R 可恢复起始位置。

图书馆已移除顶部姓名/旅人/视角/任务栏和底部操作说明；只保留准星、书本引导和近书 F。翻书结束后可返回图书馆或重新选择人物。

需要 Python 3 和支持 WebGL 的浏览器。所有运行资源包含在本文件夹中，预览服务仅监听本机，无需联网。也可在本目录执行 `python -m http.server 8894 --bind 127.0.0.1`，浏览器打开 `http://127.0.0.1:8894/开头.html`。请保留 assets 与 vendor 子目录。

图书馆、人物和古书/视频均沿用既有资产，未改源模型。镜头中出现的地图仍是原翻书工程的装饰性示意，可玩东京/悉尼地图和角色手部抓握未在本包接入。系统减弱动态开启时，翻书直接到结束画面。

切换场景会移除旧输入监听、停止旧渲染循环并释放 WebGL 资源；回到选角可以重新选人进入。刷新页面从人物选择重新开始。原 `D:\Cijian\HTML` 及 `人物卡` 交付保留。
