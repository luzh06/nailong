此间 · 三日归途
互动作品 · 网页三维旅行体验
==================================================

【怎么打开】（Windows）
1. 先把整个压缩包解压到一个文件夹（不要在压缩包里直接双击）。
2. 双击「开始体验.cmd」。会弹出一个黑色小窗口，并自动用浏览器打开作品。
   体验期间不要关闭这个小窗口；关掉它就结束了。
3. 推荐使用 Chrome 或 Edge，并开启“硬件加速”。建议使用独立显卡的电脑，
   全屏（F11）体验效果最好。首次载入约 30 秒。

若双击后没有反应：右键「开始体验.cmd」→ 以普通方式运行；或在小窗口里复制地址到浏览器。
也可以直接打开在线版（见作品提交页面上的链接）。

【怎么玩】约 10–15 分钟
· 标题页点「翻开这本书」，在四张借阅卡中选一位旅人，盖章出发。
· WASD / 方向键 行走（Shift 快走），鼠标 环视，滚轮 拉近拉远
· F  与人交谈          · C  举起相机，空格 / 单击 按下快门，滚轮 换焦段
· J  打开旅行图鉴      · B  相册          · M  地图          · Esc 暂停
· 跟着左上角“书页上的下一行”走：在东京拍下三处风景，遇见与你有缘的人、
  互相拍一张照片；夜里看烟花；最后翻开图鉴里的书页门，去悉尼的海边。
· 结尾可以保存四人回忆卡（PNG），相册里有你一路拍下的照片。
