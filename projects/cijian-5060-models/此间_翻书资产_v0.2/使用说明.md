# 此间｜古书与完整开场镜头 v0.2

2026-11-02。替代 v0.1 的外观和镜头节奏；旧文件保留。

## 查看完整镜头

- 打开 `cijian_antique_sequence.blend`，Blender 5.0.1。按 Shift＋左方向键回到开头，空格播放物体与相机动画。
- 白光、白转黑和地图淡入由合成节点完成。**普通 3D 视口不会显示这些全屏合成效果**。完整效果请看 `antique_sequence.gif`，或在 Blender 使用渲染动画；F12 仅渲染当前帧。
- 工程为 30fps、1–420 帧，约 14 秒。GIF 是低分辨率、7.5fps 的预览。

## 镜头顺序

| 时间/帧段 | 动作 |
| --- | --- |
| 0–1.6 秒 / 1–48 | 竖直古书抽出并转到阅读姿态；当前没有角色手部抓握 |
| 1.6–2.5 秒 / 48–76 | 封面打开 |
| 2.7–6.5 秒 / 83–196 | 多页弯曲翻动 |
| 6.5–9 秒 / 196–270 | 镜头推进泛黄书页，直到字迹与纸张斑点特写 |
| 9–10 秒 / 270–300 | 书页发亮、白幕逐步覆盖整个画面 |
| 10–10.5 秒 / 300–315 | 全白停留 |
| 10.5–11.5 秒 / 315–345 | 纯白平滑转黑 |
| 11.5–12 秒 / 345–360 | 全黑下切换相机，隐藏换场动作 |
| 12–13.5 秒 / 360–405 | 地图从黑暗中淡入 |
| 13.5–14 秒 / 405–420 | 地图停留 |

## 资产组成

- `cijian_antique_book.glb`：独立古书模型，磨痕棕皮封面、旧铜饰、书脊凸筋、斑点黄纸，包含取书/开封面/翻页同步动画 `CIJIAN_AntiqueBook`。
- `cijian_antique_sequence.blend`：书、镜头、纸页发光、全屏白黑合成、地图场景及完整时间线。图像已打包。
- `build_sequence.py`：生成脚本，复用上版已验证的骨骼结构；几何与纹理为项目自行制作。
- `world_map.png`：装饰性世界地图示意，用于验证转场和镜头；非正式游戏地图界面或精确地理资料，后续接入时替换为选定地图。

GLB 仅包含书本及其动画，镜头合成与地图切换需要按上述时间线在游戏引擎中接入；不能只导入 GLB 就期待出现全屏白黑效果。当前未接入图书馆、角色手部、F 按键或音效。

## 验证

闭合古书、书页特写、全白、全黑及最终地图均已在 Blender 中渲染检查。完整预览逐帧渲染合成；GLB 动画另做导入检查。游戏端尚未验证。
